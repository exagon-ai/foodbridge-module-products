Foodbridge Modules Products — Discovery Prototype

Can a wholesaler admin browse, search, filter, bulk-select, import/export, add (full field set + Unit & Price), view (packaging/inventory), edit and delete products the same way they can in the As-is reference screens — on desktop and mobile?

Current release · Version 2

Responsive Product Workspace — desktop and mobile

Version 2 mirrors the current Foodbridge Products experience across desktop tables and mobile product cards. It includes search and category filters, selection and bulk actions, direct price and stock editing, tags, product detail, add/edit drawer, Unit & Price, product-image gallery, import preview, downloadable CSV/Excel export, dark mode, and locally persistent demo data. Both launch actions below open this same responsive V2 experience.
